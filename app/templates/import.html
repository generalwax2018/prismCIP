What's understood

FortiGate: SSL VPN and IPsec dial-up tunnel-up / tunnel-down events, paired by tunnel ID. Export from Log & Report → VPN Events, or forward syslog.

Palo Alto: GlobalProtect gateway-connected / gateway-logout events (PAN-OS 9.1.3+ syslog field order).

CSV: any export with a user/account column and a start/login time column. End time and source IP are used when present.

Automatic: post logs to the API with a token from Settings:

curl -X POST -H "Authorization: Bearer pcip_…" --data-binary @vpn-events.log https://your-prismcip/api/v1/sessions
